Part 1. Overview & Philosophy

🌟 연금술사(PensionAlchemy) 개요 및 핵심 설계 철학

대한민국 금융 시장과 최신 개정 세법, 공적연금 제도를 완벽히 반영하여 100세 시대의 생애 자산 궤적과 은퇴 현금흐름을 시뮬레이션하는 종합 은퇴 설계 플랫폼입니다.

🚀
v1.3.5 신규 업데이트 릴리즈 (Release Highlights)
• 금액 단위 표기 일관성 전면 정돈: 축약 표기 및 차트 틱에서 누락되던 단위를 '원, 만원, 억원'으로 일관되게 정돈하고, 기간의미가 명확한 곳의 중복 기간단위(/월, /연)를 배제하여 직관성 강화.
• 나이별 정밀 인스펙터 헤더 개편: 나이 뱃지를 우측에 단독 배치하여 텍스트 찌그러짐을 원천 차단하고, 생애주기 단계는 도트 인디케이터가 포함된 독립 뱃지로 분리.
• 예상 순자산 카드 상하 2단 재배치: 가로 전체 100% 폭을 단독 활용하여 수십억~수천억 자산가 금액도 글자 잘림 없이 시원하고 큼직하게 표기.
• 대시보드 메인 순자산 카드 인셋 박스 구조: 총자산과 총부채를 상하 2열 분리 인셋 서머리 박스로 배치하여 좁은 화면에서도 완벽한 가독성과 심미성 확보.

📊 개발 배경: '평균의 기만'을 넘어 실질적인 노후 안전망을 세우다

2025년 대한민국 가계금융복지조사에 따르면 국내 가구의 평균 순자산은 약 4.7억 원이지만, 이는 상위 28%에 해당하는 수치입니다. 실제 대다수 가구가 밀집한 중위 순자산은 약 2.4억 원에 불과하며, 상하위 20% 간 자산 격차는 45배에 달합니다.

또한 대한민국 가구 자산의 약 75.8%가 부동산에 편중되어 있어, 은퇴 후 보유 주택만 있고 생활비 현금흐름이 메말라버리는 '하우스푸어' 위험이 극도로 높습니다. 연금술사는 이러한 비대칭 구조를 수학적 로그정규분포 모델로 시각화하고, 부동산 중심의 자산을 3층 연금 피라미드 기반의 마르지 않는 월 현금흐름으로 치환(연금술)하도록 돕기 위해 탄생했습니다.

🏛️
1. 3층 연금 피라미드 구축
1층 국민연금(물가연동 종신지급), 2층 퇴직연금(IRP 10년 이상 분할 절세), 3층 개인연금저축/보험, 그리고 보유 주택을 역모기지화하는 주택연금의 황금비율 결합.
⚠️
2. 소득 크레바스(공백기) 방어
법정 정년(60세)부터 국민연금 개시(63~65세)까지 최대 5년간 소득이 단절되는 '소득 크레바스'를 분석하고, 만 55세부터 수령 가능한 개인연금/IRP 브릿지 자금 준비 솔루션 제공.
📈
3. 글로벌 '4% 안전 인출 룰'
미국 트리니티 대학의 연구 기반으로 첫해 은퇴자산의 4%를 인출하고 매년 물가상승률만큼 증액 인출 시 30년 이상 자산 고갈 확률을 5% 미만으로 방어하는 자산 수명 보존 공식.
💎
4. 세액공제 & 복리 과세이연
연간 최대 900만원(연말정산 최대 148.5만원 환급)과 2024년 세법 개정 사적연금 1,500만원 분리과세 한도, 이자소득세(15.4%) 과세이연 복리 스노우볼 극대화.
🏥
5. 건보료 피부양자 탈락 방어
공적연금 소득이 연 2,000만원(월 167만원)을 초과할 경우 건강보험 피부양자 자격이 박탈되어 지역가입자 보험료 폭탄이 발생하는 정책 위험을 사전에 경고.
🔒
6. 100% 로컬 보안 & SAF 백업
외부 서버로 금융 개인정보를 일체 전송하지 않는 오프라인 우선(Local-First) 구조로 안드로이드 SAF(Storage Access Framework) 표준 JSON 백업/복구 지원.

📊 메뉴 1: 대시보드 (종합 진단 & 생애 자산 궤적)

내 순자산, 65세 예상 월연금, 소득대체율과 100점 만점 은퇴 건강도를 실시간으로 확인하고, 20세부터 100세까지 나이 슬라이더를 움직여 각 연령대의 순자산과 현금흐름을 시각적으로 탐색하는 메인 관제탑입니다.

🎯 주요 구성 화면 및 지표 해설

화면 컴포넌트 표시 항목 및 기능 동적 변화 및 해석 기준
1. 메인 순자산 카드 현재 나이 기준 순자산, 총자산, 총부채 자산 추가/삭제 및 시장 기대수익률, 대출 상환에 따라 실시간 자동 계산
2. 실시간 순자산 증감 티커 [기준일 / 오늘] 선택 토글, 초당 틱 단위 원 단위 누적 증감액, 초당 순자산 증감 속도(⚡ won/sec), 주기별(시간/일/월) 환산 및 유입/유출 브레이크다운 자산 기대수익률, 정기 소득 및 생활소비·이자비용을 종합하여 초 단위로 변화하는 순자산 증감 속도를 라이브 체감. 공통 기준일 변경 시에도 '현재 순자산'은 보유 자산 가치로 절대 보존되며 기준일 시점의 기초 순자산과 누적 순증가액이 정합성 있게 연동됨
3. 은퇴 준비 건강도 점수 0 ~ 100점 만점, S/A/B/C/D 등급 및 실시간 피드백 소득대체율(30점), 자산고갈여부(40점), 크레바스방어(20점), 자산다각화(10점) 종합 채점
4. 소득 크레바스 경고 배너 공백기 연령 구간, 월평균 부족액, 총 필요 브릿지자금 은퇴 나이 < 국민연금 개시 나이일 때만 동적으로 노출되어 경각심 제공
5. 2x2 핵심 메트릭 그리드 소득대체율, 자산고갈시점, 65세월연금, 피크자산 권장 소득대체율(50~60%) 달성 여부 및 100세 이상 평생 자산 보존 가능 여부 표시
6. 생애 자산 궤적 차트 순자산(초록), 총자산(파랑), 부채(빨강) 궤적 곡선 은퇴 시점 음영 처리 및 나이 슬라이더 조작 시 세로 커서와 포인트 실시간 동기화
• 시뮬레이션 자료 다운로드 차트 바로 아래 컴팩트 버튼 ➜ 저장 위치 직접 지정 원하는 폴더(내장메모리, 다운로드 등)를 지정하여 27개 전 지표 UTF-8 BOM CSV 파일 다운로드
7. 나이별 정밀 인스펙터 20~100세 슬라이더, 순자산, 월소득, 생활지출, 순현금흐름 슬라이더 이동 시 해당 나이의 축적기/크레바스/은퇴기 판정 및 세금/건보료 경고 실시간 갱신
8. 3층 연금 적층 바 차트 55~90세 연령별 1층 국민, 2층 퇴직, 3층 개인, 주택연금 스택 연금 개시 연령과 수령 종료 연령에 따른 적층 구조 시각화
9. 자산 배분 도넛 차트 금융자산, 연금자산, 부동산, 부채 비중 도넛 포트폴리오의 유동성 및 특정 자산(부동산 등) 쏠림 상태 진단
10. 순자산 백분위 분포 차트 2025 가계금융복지조사 로그정규분포 곡선 및 내 위치 중위값(2.4억), 평균값(4.7억) 기준선 및 전체 기준일이 반영된 내 현재 실시간 순자산(displayNetWorth) 기반 상위 % 실시간 마킹
🎛️ 사용자 동적 조작 방법
  • 나이 슬라이더 탐색: 20세부터 100세까지 슬라이더를 드래그하여 본인이 관심 있는 특정 나이(예: 은퇴 직후 60세, 국민연금 개시 65세, 고령기 80세)를 지정합니다.
  • 실시간 지표 확인: 해당 나이의 순자산 규모, 월 총소득, 물가상승률이 누적 반영된 월 생활비를 비교합니다.
  • 흑자/적자 판정: 월 소득에서 지출을 뺀 월 순현금흐름이 흑자(잉여 자금)인지 적자(부족 자금)인지 즉각 판정됩니다.
📈 동적 설정에 따른 결과 변화 분석
  • 연금 실수령액 분해: 연금 세전 총액에서 예상 원천징수 소득세가 차감된 순수 수령액이 계산됩니다.
  • 건보료 피부양자 탈락 경보: 선택한 나이에 공적연금 소득이 연 2,000만원을 초과하면 주황색 경고 배너가 즉시 나타납니다.
  • 사적연금 1,500만 초과 경보: 연금저축/IRP 수령액이 연 1,500만원을 초과하여 16.5% 분리과세가 적용되는 구간일 경우 청록색 안내 배너가 점등됩니다.

💼 메뉴 2: 자산 및 정기 소득 관리

예금, 적금, 주식, 채권, ETF, 원자재, 부동산, 가상자산 및 대출(부채) 등 보유 자산과 은퇴 전 근로/사업/임대소득을 등록하고, 기대수익률과 부채 상환 방식을 정밀 설정합니다.

🎯 자산 분류 체계 및 대출 4대 상환 방식

등록된 모든 자산은 100세 시뮬레이션 동안 입력된 기대수익률에 따라 매년 복리로 자연 성장하며, 대출(부채)은 선택된 상환 방식에 따라 원리금을 갚아나가면서 매년 현금 유출을 일으킵니다.

상환 방식 특징 및 월 납입 구조 시뮬레이션 반영 메커니즘
1. 원리금균등분할 매월 원금과 이자의 합계가 동일하게 납부 만기 연도까지 매년 균등한 현금 지출 발생 후 기말 잔액 0원 소멸
2. 원금균등분할 매월 원금은 동일하고, 잔액 감소로 이자는 점차 감소 초기 현금 지출 부담이 크지만 해가 갈수록 지출이 경감되는 현실적 추이 반영
3. 만기일시상환 기간 중에는 매월 이자만 납입 후 만기일에 원금 전액 상환 만기 도래 연도에 큰 폭의 현금 유출이 발생하여 금융자산 잔액 급감
4. 거치식 (이자만) 원금 상환 없이 매년 대출금리에 해당하는 이자만 지속 지출 부채 잔액이 유지된 채 매년 이자 비용만 발생하여 순자산 증가율 둔화
🎛️ 자산 및 소득 동적 설정 항목
  • 자산 유형: 예금, 적금, 주식, 채권, ETF/펀드, 원자재, 부동산, 가상자산, 대출/부채 선택.
  • 평가 금액 & 기대수익률: 현재 평가금액(원)과 장기 보수적 연평균 기대수익률(대출인 경우 연 대출금리) 입력.
  • 부채 만기년수: 잔여 대출 상환 기간(년)을 설정하여 은퇴 전 부채 청산 여부 점검.
  • 정기 소득 종료 나이 & 상승률: 근로/사업 소득의 은퇴 시기(예: 60세)와 연간 임금상승률 설정.
  • 입력 기준일(baseDate) & 퀵 캘린더: 잔액을 평가한 기준일(YYYY-MM-DD)을 설정하며, 상단 연/월 칩 터치 한 번으로 원하는 날짜를 초고속 탐색 가능.
📈 시뮬레이션 결과 반영 원리
  • 잉여 현금의 복리 재투자: 소득이 지출+대출상환액보다 많을 때 남은 잉여금은 유동 금융자산에 자동으로 편입되어 복리 증식됩니다.
  • 적자 시 자산 인출 순서: 은퇴 후 소득이 부족할 경우, 유동 금융자산에서 우선 인출되며, 금융자산이 바닥나면 부동산 자산이 차감(주택 유동화 가정)됩니다.
  • 실시간 초당 가산: 개별 항목의 기준일(미입력 시 전체 공통 기준일 자동 상속)부터 현재 시각까지 경과된 시간에 비례하여 초당 수익이 라이브로 가산됩니다.

🛡️ 메뉴 3: 3층 연금 관리 (국민·퇴직·개인·주택연금)

출생연도에 따른 국민연금 법정 개시 연령을 자동 판정하고, 조기(-5년)/연기(+5년) 슬라이더를 통해 감액 및 증액 효과를 실시간으로 확인하며, 퇴직연금·개인연금·주택연금의 황금비율을 최적화합니다.

🎯 국민연금 조기/연기 슬라이더 & 세법 적용 체계

[국민연금 조기/연기 수령 공식]
• 조기수령 (최대 5년 앞당김): 1년당 6.0% 감액 (최대 -30.0%)
  수령액 = 정상월연금액 × [1.0 - (조기년수 × 0.06)]
• 연기수령 (최대 5년 늦춤): 1년당 7.2% 증액 (최대 +36.0%)
  수령액 = 정상월연금액 × [1.0 + (연기년수 × 0.072)]
• 물가상승률(CPI) 복리 연동: 매년 물가상승률을 100% 반영하여 수령 가치 보존
🎛️ 사용자의 슬라이더 조작
  • -5년 ~ +5년 슬라이더 이동: 앱 내 연금플랜 화면의 슬라이더를 드래그하면 감액률(-30%)부터 증액률(+36%)까지 즉시 변동됩니다.
  • 개시 나이 및 예상액 갱신: 예를 들어 정상 65세 수령액이 160만원인 경우, 5년 조기(60세) 시 112만원(-30%), 5년 연기(70세) 시 217.6만원(+36%)으로 실시간 재계산됩니다.
  • 대시보드 자동 연동: 슬라이더를 조정하는 즉시 대시보드의 생애 궤적, 소득 크레바스 기간, 3층 연금 적층 바 차트가 일제히 재시뮬레이션됩니다.
💡 연금 종류별 핵심 절세 & 회계 포인트
  • 퇴직연금 (IRP): 10년 이상 분할 수령 시 1~10년차는 퇴직소득세의 30%를 감면받고, 11년차부터는 40% 감면 혜택을 받습니다.
  • 개인연금저축: 2024년 세법 개정으로 연간 1,500만원까지 저율 분리과세(5.5%~3.3%)가 적용되며, 1,500만원 초과분에 대해서만 16.5% 분리과세됩니다.
  • 사적연금 납입금 보존: 급여에서 직접 차감 납입되는 연금저축/IRP 납입금은 가계 유출이 아닌 '연금 적립금 자산으로의 대체'이므로, 실시간 순자산에서 이중 차감 없이 온전히 자산으로 보존됩니다.
  • 동적 수령액 사전 자동 계산: 퇴직연금·개인연금 등록 시 적립금/납입액과 수령 기간(기본 25년)을 기반으로 진입 즉시 월 예상 수령액이 자동으로 정밀 산출됩니다.
  • 예상 적립금 전용 단독 줄 레이아웃: 개시 시점 예상 적립금 금액을 상하 세로 적층 구조로 단독 배치하여, 고액 자산이나 큰 폰트에서도 금액이 2줄로 꺾이지 않고 시원하게 표시됩니다.
⚠️
국민연금 조기/연기 수령 황금나이 판정 가이드
• 조기(60세) vs 정상(65세): 손익분기 교차 나이는 만 76~77세입니다. 76세 이전에 사망할 것으로 예상되면 조기수령이 유리하지만, 77세 이상 생존 시 정상수령의 누적 총액이 역전합니다.
• 정상(65세) vs 연기(70세): 손익분기 교차 나이는 만 81~82세입니다. 82세 이상 장수할 경우 연기수령(+36%)의 누적 수령액이 압도적으로 많아집니다.

🌟 [v1.3.3 신기능] 전체 공통 기준일 도입 & 생활소비 분리 시뮬레이션

가계의 실시간 순자산 증가를 통일된 시점부터 정확하게 측정하기 위해 전체 공통 기준일(globalBaseDateTime)을 도입하고, 은퇴 전 생활비와 은퇴 후 지출을 분리하여 정밀 시뮬레이션을 수행합니다:

📅
1. 전체 공통 기준일 (yyyy.MM.dd 기준)
가계의 실시간 총자산 및 순자산 누적 증가액을 계산하는 통합 기준 시점입니다. 불필요한 시간 입력을 배제한 YYYY-MM-DD 날짜 전용 입력과 초고속 연/월 칩 피커(FastDatePicker)로 과거 또는 기준일을 1초 만에 지정할 수 있습니다.
🛒
2. 은퇴 전: 현재 월 생활 소비 지출
현재 나이부터 은퇴 직전까지 매월 소득에서 차감되는 실제 생활비입니다. 물가상승률이 누적 적용되며, 근로소득에서 생활비와 부채 원리금을 뺀 잉여금이 매년 금융자산(저축/투자)으로 정밀하게 축적됩니다.
🎯
3. 은퇴 후: 미래가치 자동 환산 지출
설정에는 편안한 입력을 위해 '현재 물가 기준 필요 지출'을 기재합니다. 입력 즉시 은퇴 시점까지의 연간 물가상승률이 복리로 자동 환산된 실제 은퇴 시점 미래가치(FV)가 실시간으로 안내되며, 지정한 은퇴 나이부터 해당 금액이 소비로 계산됩니다.

공식 1

1층 국민연금 수령액 산출, 물가상승률(CPI) 복리 연동 및 조기/연기 수령 공식

1) 물가상승률(CPI) 복리 연동 수령액 공식:

P(t) = P₀ × (1 + i_cpi)^(t - t₀)

2) 조기노령연금 감액 공식 (-0.5%/월, -6%/년, 최대 5년 -30%):

P_early = P(t) × [1 - (0.005 × m_early)]

3) 연기연금 증액 공식 (+0.6%/월, +7.2%/년, 최대 5년 +36%):

P_delayed = P(t) × [1 + (0.006 × m_delayed)]

• 조기수령 vs 정상수령 손익분기 교차 나이: 만 76~77세 | 정상수령 vs 연기수령 손익분기 교차 나이: 만 81~82세

공식 3

대출 4대 원리금 상환 방식 금융수학 공식

// 1. 원리금균등분할상환 (PMT 공식)
PMT = P × [r(1 + r)^n] / [(1 + r)^n - 1]
Interest_k = B_(k-1) × r, Principal_k = PMT - Interest_k

// 2. 원금균등분할상환
Principal_k = P / n, Interest_k = B_(k-1) × r, PMT_k = Principal_k + Interest_k

// 3. 만기일시상환 & 거치(이자만)
PMT_k = P × r (만기 k=n 시점에 원금 P 전액 일시 상환)
공식 4

생애 현금흐름 밸런싱 및 자산 증감 공식 (Cash Flow & Asset Transition)

// 월 순현금흐름
NCF = (Income_work + Pension_net) - (Expenses_living + Contrib_personal + DebtService)

// 잉여금 발생 시 (NCF > 0): 금융자산 자동 재투자 복리 증식
Assets_fin(t+1) = Assets_fin(t) × (1 + r_fin) + (NCF × 12)

// 적자 발생 시 (NCF < 0) 인출 우선순위:
1순위 금융자산 인출 ➜ 2순위 부동산 자산 처분 충당 ➜ 3순위 누적 순적자 전이
공식 5

공통 기준일(T_global) & 개별 항목 기준일(T_item) 연동 실시간 자산증가속도($v_w$) 및 누적 증감 공식

// 1. 공통 기준일(T_global)과 개별 항목 기준일(T_item) 간의 유효 경과시간 t_eff 산출
if (T_item <= T_global):
    t_eff = T_now - T_global   // 전체 기준일 시점에 이미 평가 반영된 항목
else if (T_item > T_global):
    t_eff = T_now - T_item    // 기준일 이후 신규 취득/등록된 항목

// 2. 가계 부문별 초당 유입/유출 속도 (wps, Won Per Second)
wps_asset_i = (Value_i × r_i) / 31,557,600초 (복리운용 수익)
wps_pension_p = (PensionValue_p × r_p) / 31,557,600초 (퇴직/개인연금 복리수익)
wps_income_k = (Income_k × 12) / 31,557,600초 (정기소득)
wps_debt_d = (Debt_d × r_d) / 31,557,600초 (대출이자 비용)
wps_living = (Expense_living × 12) / 31,557,600초 (생활비 지출)
wps_contrib = (Contrib_private × 12) / 31,557,600초 (개인연금 납입액 ➜ 자산 내 이전 보존 처리)

// 3. 자산증가속도(=Wealth Velocity, $v_w$, 단위: 원/초)
v_w = (Σ wps_asset + Σ wps_pension + Σ wps_income) - (Σ wps_debt + wps_living)

// 4. 누적 순증가액 (기준일 기준 & 오늘 기준)
Gain_baseDate(t) = Σ(t_eff_i × wps_asset_i) + Σ(t_eff_p × wps_pension_p) + Σ(t_eff_k × wps_income_k) - [Σ(t_eff_d × wps_debt_d) + t_eff_global × wps_living]
Gain_today(t) = v_w × ElapsedSeconds_from_today_midnight
공식 6

6대 전문 재무 계산기 핵심 수학 공식

// 1. 적립 복리 미래가치 (월복리 기말급)
FV = PMT × [ (1 + r/12)^(12n) - 1 ] / (r/12) + PV × (1 + r)^n

// 2. 4% 룰 기반 은퇴 목표 필요자산
TargetWealth = (Expense_monthly - Pension_monthly) × 12 / 0.04 = Deficit_annual × 25

// 3. 자산 고갈 타이머 (NPER 로그 역산)
n = ln( W / (W - PV × r) ) / ln(1 + r) (단, W > PV × r 일 때)

// 4. 연금저축/IRP 900만원 세액공제 및 환급금 재투자
Refund = min(Contrib, 9,000,000) × Rate (16.5% or 13.2%)
